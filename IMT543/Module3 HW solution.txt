Problems:
•	Items Purchased contains multiple values
•	Customer and item data are mixed
•	Redundant data (salutation repeated)

1NF
Action Taken
Split multiple items into separate rows.

CustomerID	Full Name	Physical Address	Item Purchased	Salutation
1		John Smith	12th Street Block 7	Laptop		Mr.

4		Emily Clark	Cedar Avenue No. 5	Sofa		Ms.
4		Emily Clark	Cedar Avenue No. 5	Coffee Table	Ms.
5		Richard Lee	Oak Street No. 14	Bicycle		Mr.

------------------------------------------------------------------------------------------------------------

2NF
Rule:
•	Must already be in 1NF
•	Remove partial dependencies
•	Non key attributes must depend on the entire primary key
Problem Identified
•	Customer details depend only on CustomerID
•	Item Purchased depends on purchase, not the customer

Solution
Split into separate tables.

3NF
Rule:
•	Must be in 2NF
•	Remove transitive dependencies
•	Non key attributes must depend only on the primary key
Problem Identified
•	Salutation is descriptive and reusable (Mr., Ms.)
•	Causes redundancy
Solution
Move salutation into its own lookup table.

Salutations Table (3NF)

1		Mr.
2		Ms.

Salutations Table

sql
CREATE TABLE Salutations (
    SalutationID INT PRIMARY KEY,
    Salutation VARCHAR(10) NOT NULL);

Insert Sample Data
sql
INSERT INTO Salutations (SalutationID, Salutation)

________________________________________

Customers Table
sql

CREATE TABLE Customers (
    CustomerID INT PRIMARY KEY,
    FullName VARCHAR(100) NOT NULL,
    PhysicalAddress VARCHAR(200) NOT NULL,
    SalutationID INT NOT NULL,
    FOREIGN KEY (SalutationID) REFERENCES Salutations(SalutationID));

Purchases Table
sql
CREATE TABLE Purchases (
    PurchaseID INT PRIMARY KEY,
    CustomerID INT NOT NULL,
    ItemPurchased VARCHAR(100) NOT NULL,
    FOREIGN KEY (CustomerID) REFERENCES Customers(CustomerID));

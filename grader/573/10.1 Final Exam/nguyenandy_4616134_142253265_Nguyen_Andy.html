To explore who engaged in extramarital affairs, I first created a binary variable that indicates whether a respondent had any affair activity using the 'affairs' variable. This new variable equals 1 if the respondent reported any amount of affair involvement and 0 otherwise.

Modeling the data using this binary outcome has several advantages. It simplifies interpretation, allowing us to focus on the broader question of whether an affair occurred rather than the exact amount of time spent having affairs, which may be difficult to measure reliably. A binary outcome is also easier to model with logistic regression and tends to be more robust to extreme values, such as unusually high affair scores that could skew results.

However, this approach also has important limitations. By converting a continuous measure into a binary one, we lose information about the intensity or frequency of affairs. Someone who had one brief encounter is treated the same as someone with extensive affair activity, which may mask meaningful differences in behavior. Additionally, the threshold of “greater than zero” assumes that any reported affair, no matter how small, is equally significant, which may not reflect the real-world variation captured in the original data.

#List of all possible predictors
predictors = ["age", "yrs_married", "children", "religious", 
              "educ", "occupation", "occupation_husb", "rate_marriage"]

#Start with an empty model
selected = []

#Stepwise selection using AIC
def compute_aic(vars_list):
    formula = "had_affair ~ " + " + ".join(vars_list)
    model = smf.logit(formula=formula, data=affairs).fit(disp=False)
    return model.aic, model

best_aic = float("inf")
best_model = None

for var in predictors:
    trial_vars = selected + [var]
    aic, model = compute_aic(trial_vars)
    if aic < best_aic:
        best_aic = aic
        best_model = model
        selected.append(var)

print("Selected variables:", selected)
print(best_model.summary())

#Encode categorical variables
df_encoded = pd.get_dummies(df, drop_first=True)

#Stepwise forward selection function
def forward_selection(data, response):
    remaining = list(data.columns)
    remaining.remove(response)
    selected = []
    current_score, best_new_score = 0.0, 0.0
    
    while remaining and current_score == best_new_score:
        scores_with_candidates = []
        for candidate in remaining:
            formula = "{} ~ {}".format(response,
                                       ' + '.join(selected + [candidate]))
            score = sm.OLS.from_formula(formula, data).fit().rsquared_adj
            scores_with_candidates.append((score, candidate))
        
        scores_with_candidates.sort()
        best_new_score, best_candidate = scores_with_candidates.pop()
        
        if best_new_score > current_score:
            remaining.remove(best_candidate)
            selected.append(best_candidate)
            current_score = best_new_score
    
    return selected

best_vars = forward_selection(df_encoded, "charges")

  1. A set of functions necessary for scraping the lyrics of a specific artist.
  2. An example implementation of using your functions.
  3. A file of example output from your notebook implementation.

The specific approach that you take to structuring your code is up to you, but the final output .csv data should have the following columns (each row is a song from an artist that you choose):

  • Column 1: artist
  • Column 2: album
  • Column 3: song title
  • Column 4: URL of song lyrics
  • Column 5: song lyrics (all of the lyrics in one column)
  • Column 6: number of words in the song

Data Scraping: The actual scraping of data should be supported by separate functions that accomplish these tasks:

  1. Given an artist, identify all of their albums, songs, and links to songs.
  2. Given a set of song links (from step 1), collect the lyrics to each song and store them in a data frame.

In order to do this, you'll need to understand the structure of your lyrics site. The site you use is up to you, but all of this information should be available on lyrics.com.

Data Processing:

Once you've scraped the data, you'll need to do some simple text analysis to generate your columns of interest (feel free to do this as part of step 2 above, the collection of lyrics for each song or as a separate step entirely). Recall you are aiming to count the number of words in each song.

Example Implementation:

You should demonstrate the implementation of your data scraping functions with a particular artist. To do this you can simply set an artist, and run your scraping functions. The way in which you choose to structure your functions is up to you, as long as the implementation and documentation is clear. One way in which we'll test this is changing the artist to confirm the flexibility of your implementation.
